ChartSDK 적대적 호스트 CSS 스트레스 테스트

실행 중인 서버와 차트별 임베드 키가 필요합니다. 값을 채우고 렌더를 누르면 각 패널의 적대적 CSS 안에서 같은 차트를 명령형으로 그립니다. 각 패널 설명의 기대대로 보이면 방어 성공입니다.

A. 전역 div{...} 리셋 (비-!important)

기대: 캡션은 인라인 방어로 회색·작은 글씨 유지(빨강·30px 아님). 차트 본체는 canvas 라 무관.

B. 전역 canvas{max-width:50% !important}

기대: SDK 가 canvas 에 max-width:none 을 걸어 표시 크기·클릭 좌표가 정상.

C. 조상 overflow:hidden + 낮은 높이

기대: 툴팁이 confine:true 로 컨테이너 안에 머물러 잘리지 않음(막대 위 hover).

D. 조상 transform:scale(0.85)

기대: hover 시 툴팁이 커서/막대 위치에서 크게 어긋나지 않음.

E. 다크 배경 #111

기대: 차트에 불투명 흰 배경이 깔려 검정 축 라벨·텍스트가 보임(투명 아님).

F. 높이 미지정 컨테이너

기대: 컨테이너에 height 가 없어도 SDK 320px 폴백으로 차트가 보임(0px 붕괴 아님).

G. 클라이언트 position:absolute

기대: SDK 가 relative 로 덮어쓰지 않고 클라이언트의 absolute 배치를 존중.

H. 공식 훅 .chartsdk-caption{...!important}

기대: 의도적 오버라이드는 먹혀서 캡션이 초록·굵게. (클래스+!important 조합만 통과)
