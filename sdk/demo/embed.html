ChartSDK 임베드 데모

실행 중인 서버(EmbedController)와 발급된 임베드 토큰이 필요합니다. 아래 값을 채우고 렌더를 누르면 명령형 ChartSDK.render()로 그립니다.

실제 페이지에 붙여넣는 임베드 스니펫(선언형)

<div data-chart-id="12"
     data-auth-token="eyJ..."></div>
<script src="https://your-host/sdk.js"></script>

sdk.js 로드 시 [data-chart-id]를 자동 스캔해 렌더합니다(SPA는 ChartSDK.scan()/ChartSDK.render()).
