## 8. 주요 리스크 및 남은 과제

1. Figma 1:1 원본 대조
   - 여러 세션에서 시도/설정이 있었지만, 일부 세션에서는 MCP tool 미노출 또는 URL/node 조건 문제로 완전 대조가 미완료로 기록됨
   - 2026-06-29에는 현재 UI를 새 Figma 파일에 sync한 기록은 있음

2. Docker/WSL 환경 안정성
   - Docker Desktop backend, WSL, `vmcompute`, docker engine pipe 문제 진단 기록이 있음
   - 개발 환경 재현성을 위해 Docker Desktop 상태 체크 절차 문서화가 필요함

3. 런타임 포트 충돌
   - 8080 기존 Java process, 5433 PostgreSQL connection refused, 3000 frontend 미기동 등 여러 차례 확인됨
   - dev server 시작/종료 자동화와 port ownership 점검이 필요함

4. E2E 종료 hang 및 `.next` 충돌
   - Playwright 테스트 자체는 통과했으나 프로세스 종료 hang이 문서화됨
   - `next build`와 dev E2E 동시 실행 시 `.next` 산출물 충돌 이력이 있음

5. 생성 멱등성
   - `docs/트러블슈팅_기록.md` 기준 `POST /charts`의 idempotency key는 후순위로 남아 있음

## 9. 결론

이 프로젝트는 문서 기준 2026-06-10에 PRD가 시작됐고, 로컬 파일 기준 2026-06-19에 주요 코드와 문서가 대량 생성됐으며, git 기준으로는 2026-06-22에 공식적인 초기 커밋들이 만들어졌다. 2026-06-22에는 MVP 골격, 2026-06-24에는 실제 backend/DB/API/실DB E2E, 2026-06-25에는 운영성과 데이터 정합성, 2026-06-26에는 UI 실사용성, 2026-06-29에는 리팩터링과 raw tuple 확장 및 문서 갱신이 집중적으로 진행됐다.

2026-06-30 조사 당시 `main`은 `origin/main`과 동기화되어 있었고 작업트리는 깨끗했다. 저장소 내부 AI 기록은 비어 있었지만, 당시 접근 가능한 전역 Codex 세션 로그에서 관련 작업 기록이 다수 확인됐고 커밋/문서/실행 산출물과 대체로 맞물렸다.
